# Documentation index

**Roadmap item 72.** Every document in this tree, with the question it answers.
`scripts/check_docs.py` fails CI when a document exists but is not listed here, when a required
document is missing, or when a relative link in any Markdown file points at nothing.

where GitHub looks for them; `check_open_source.py` enforces their presence and contents.
