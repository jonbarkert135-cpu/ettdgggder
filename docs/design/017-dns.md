# 017 — DNS and network privacy

**Roadmap item 17.** Status: landed and host-tested
(`src_overrides/bedrock/net/dns_settings.{h,cc}`).

## The guarantee

**The user can always name who resolves their DNS.** Not "encrypted, trust us" — an operator
name, in settings, next to the switch.

And: no query ever goes through infrastructure belonging to this project. No Bedrock resolver, no
Bedrock fallback, no bootstrap endpoint (roadmap item 4). A test asserts no shipped provider URL
mentions Bedrock; the human rule behind it is that we never add one.

## Modes

| Mode | Who sees the queries |
|---|---|
| System (default) | the OS resolver — usually the ISP or router. Bedrock changes nothing |
| Secure preset | the provider the user picked, named with its operator and jurisdiction |
| Secure custom | the endpoint the user typed; we say plainly that we cannot tell them who runs it |
| Secure strict | that provider only — resolution fails rather than falling back to plaintext |

The default is the **system** resolver on purpose. Silently moving every user's DNS to one
company the moment they install a privacy browser would be exactly the pattern the project
exists to avoid — even if that company is a good one.

Custom resolvers must be `https://` (DoH) or `tls://` (DoT). A plaintext custom resolver is just
a different party watching in the clear, so it is refused rather than offered as a "choice".

## Fallback

`kSystemWithWarning` (default) resolves through the OS when the secure resolver is unreachable —
names resolve, and the user is told this is a downgrade. `kFailClosed` fails the navigation.
Strict mode *is* fail-closed and overrides the setting rather than letting a configuration
contradict itself.

## Leaks we do not paper over

Encrypted DNS is not a cloak, and the settings page lists the gaps instead of implying otherwise:
resolver bootstrapping, other applications on the device still using the OS resolver, captive
portal detection, TLS SNI (visible without Encrypted Client Hello), the destination IP itself,
and local/`.onion` names that never go to the public resolver.
