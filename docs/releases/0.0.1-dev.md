# Bedrock 0.0.1-dev

**Channel:** nightly
**Released:** 2026-08-23

The first build anyone other than the build machine can run. Published as a GitHub pre-release:
<https://github.com/jonbarkert135-cpu/ettdgggder/releases/tag/v0.0.1-dev> —
`bedrock-0.0.1-dev-linux-x64.tar.zst`, 313 093 368 bytes,
sha256 `54be5449d7ffab64f926d0f368326af09956952b55c457137c97f15a42b6c178`.

## Version number

`0.0.1-dev` (not a channel version from `updater/release_channels.cc`; nothing is on a release
channel yet, and this note exists so the first downloadable artifact is documented like any other).

## Chromium base version

`151.0.7922.173` (commit `a96602f30358e9b5d256a0464e7e4d4bec223004`) — matches
`build/chromium.pin`.

## Security fixes

None. This is the pinned upstream revision with no security work of our own on top; it is already
older than upstream stable and must not be treated as a maintained build.

## Privacy changes

- `webrtc.ip_handling_policy` now defaults to `default_public_interface_only`, supplied by
  `settings/defaults.h` (`webrtc_privacy`) instead of Chromium's default. WebRTC does not expose
  local network addresses. This is the only enforced protection in the build — see
  `build/ENFORCEMENT.md`, "Build 2".
- Everything else is stock Chromium behaviour, including Google service integrations that the
  overlay has not disabled yet. Do not read the absence of Bedrock UI as the absence of upstream
  network activity.

## Dependencies

None added, removed or changed since the last commit on `main`. The archive ships Chromium's own
component libraries only; `docs/THIRD_PARTY.md` and `build/sbom.json` are unchanged.

## Known issues

- Linux x64 only; no Windows or macOS build exists.
- Component build: it starts only through `run-bedrock.sh` (or with `LD_LIBRARY_PATH` set to the
  unpacked directory). No installer, desktop entry, auto-update or signature.
- No Bedrock branding, name or icon in the UI — it looks like Chromium.
- 11 of the 12 shipped defaults are not wired to the engine; no content blocking, fingerprint
  protection, storage isolation, Tor mode or Bedrock settings UI runs.
- Crash reporting has no handler (Crashpad is not integrated), so a crash leaves no local report.
- Unstripped, unhardened, unaudited. Use a throwaway profile.
